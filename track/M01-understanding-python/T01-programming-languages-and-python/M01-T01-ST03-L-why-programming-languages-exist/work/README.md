# Why Programming Languages Exist


## Why Does a Computer Need Instructions?
A computer doesn't understand what we want unless we provide detailed instructions.

## Why Can We Not Build Applications Using Normal Human Language?
Because computers can't understand human language. It only understands 0's and 1's (Binary) form of language.

## What Problem Do Programming Languages Solve?
Programming languages solve the problem of communication between humans and computers. They allow us to write instructions in a human-readable format, which is then translated into machine code that the computer can understand.

## Why Is Machine Language Difficult for Humans?
Machine language is difficult for humans because it is written in binary code (0s and 1s), which is not easy for humans to read and understand. Also it is very difficult to write and understand.

## How Does Python Help?
Python helps us to write instructions in a human-readable format, which is then translated into machine code that the computer can understand.
