# Programming vs Programming Language

## What Is Programming?
Programming is the process of creating step-by-step instructions to solve a problem or perform a task.

## What Is a Programming Language?
Programming language is a language used to write instructions for computers. Examples: Python, Java, C, etc..

## What Is Python?
Python is an interpreted, high-level, general-purpose programming language.

## What Is Syntax?
Syntax is the set of rules that defines the structure of a programming language.

## Programming and Python
Programming is the process of creating step-by-step instructions to solve a problem or perform a task. Python is a programming language used to write instructions for computers.

## What Remained the Same?
Both pseudocode and Python programs have variables, loops, and conditional statements.

## What Changed?
In pseudocode, we used natural language like english to write instructions. In Python, we used a specific syntax to write instructions.

## My Final Understanding
Programming helps me: Solve problems by creating logical and step-by-step instructions.

Python helps me: Write those instructions in a programming language that a computer can execute.

Syntax tells me: How to write instructions in a programming language.
